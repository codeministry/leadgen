Sources lists where the offers come from, how much each one yields, and which configuration layer defined it: the shipped default or your own configuration. The table shows, per source, the last run, the documents read, the offers extracted, how many survived the filter, the hit rate, and whether the extracted count matches the count the source announced.

Open a source to see its recent runs and the block that defines it, with every secret masked. The screen reads and never edits; adding a source is a new block in the configuration, not a deploy.

**Tip:** a source whose extracted count keeps falling below the announced one has most likely changed its layout. That is the first place to look when a day feels quiet.
