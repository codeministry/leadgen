Review is where you add an offer by hand: an ad a contact forwarded, or one you found yourself. Drop a Markdown file onto the upload area, and it waits in the queue until you have seen what was read from it.

Open a document from the queue to check its fields against the text. Fields in the frontmatter are read as they are; without frontmatter, a language model reads them out of the text and marks each one, so check those before you confirm. **Confirm** hands the file to the next run, and **Discard** drops it.

**Tip:** if the queue says an upload is already in the pipeline, confirming it anyway is harmless. Deduplication folds the two into one entry that names both.
