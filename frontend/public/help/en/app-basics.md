The header carries what is the same on every screen: the navigation, the run, the settings and this help.

<!-- screenshot: run-confirm -->

**Run ingest** starts a run by hand, after asking once, because a run reads the mailbox, calls the configured models and spends part of the call budget. While a run is going the button waits, and the stage it has reached shows beside it. Where more than one scoring model is configured, a select before the button picks the one the next run judges with; your choice is remembered in this browser.

<!-- screenshot: settings-panel -->

The gear opens the settings: the colour theme (like the system, light or dark), the language (like the browser, English or German) and the version that is running. The circled question mark opens this help at the chapter of the screen you are on.

The keyboard works on the shortlist: **j** and **k**, or the arrow keys, move through the list and open the next offer, and **a** archives the one that is open. Escape closes an open offer on the pipeline board, and closes any dialog or panel.

The app can be installed from the browser's own install button and then runs in a window of its own. Its screens load without a connection; what they show still comes from the server. When a new version is out, a notice offers to reload into it.

**Tip:** install the app on the machine you work on every morning. It opens straight into the dashboard, and an update never catches you mid-way, because it waits for your reload.
